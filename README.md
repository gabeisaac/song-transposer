# Song Transposer

Free ShrimpWeb tool. Paste a chord chart and shift it by semitones. Chords can sit on their own line or in brackets like `[Am]`. Slash-chord bass notes move with the shift.

Live: https://shrimpweb.com/transpose/

Static page: `index.html`, `styles.css`, `script.js`. Open `index.html` in a browser. To pitch-shift an audio file instead, see the [audio pitch transposer](https://shrimpweb.com/pitch/).
